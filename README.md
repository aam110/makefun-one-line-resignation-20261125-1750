A one-line resignation letter from a leap-day cron job — it works one day every
four years, and HR still docked it for the other three.

Entry for the [make.fun bounty](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

## Run

```sh
node main.ts
```

Writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
Node standard library only, deterministic, no network.
